        THE FIELD GUIDE
      

      
Create. Prepare. Present.

      

        Read the illustrated user guide ↗ —
        modern and fullscreen DOS interfaces, controls, and step-by-step workflows.
      

      

        A working interpretation of ExecuVision, built from contemporary reviews, library booklets,
        and independently recovered graphics formats.
      

      

        

          
01 / Make a slide

          

            Draw, type, fill areas, or place a chart. Select a region to move it, copy it, or save a
            native PIX fragment. Pixmix treats color index 0 as transparent.
          

        

        

          
02 / Bring your library

          

            Open EV files with their TOC, disk ZIPs, original 7z packages, or raw 160/320 KiB DOS
            disk images. Add a graphic as a slide or place it over your composition.
          

        

        

          
03 / Take the stage

          

            Prepare arranges slides. Run offers manual or timed playback, with multiple independent
            straight-line motions, nine speeds, start delays, and optional trails. Choose a motion
            from the list below the canvas to edit it, or select another region and Add motion.
            Print creates slide handouts.
          

        

        

          
04 / Keep your work

          

            Export video records the whole presentation or the current slide, including palettes and
            motions. Save project preserves pixels, palettes, motion, and original metadata. Save
            regularly: closing the tab discards unsaved work. Native EV export writes the recovered
            raster format; original-program compatibility is experimental.
          

        

      

      

        What is reconstructed, and what is interpreted?
        

          The five original tasks and core drawing, text, chart, cut/paste, palette, motion, and
          presentation behaviors follow the 1984–1985 reviews. Fonts, pointer controls, undo, JSON
          projects, and this interface are new implementations. Exact historic fonts, palette
          records, object records, and native animation records remain unresolved. Imported native
          files retain opaque metadata, which may no longer describe edited pixels. New EV files use
          a minimal inferred container. Native TOCs provide names for this app; legacy directory
          metadata is unverified. Nothing in the cited YouTube history video's movie footage was
          used as UI evidence.

DOS COMMAND REFERENCE

      

        Keyboard-operated CGA-inspired interface. This is a new work-alike, not the original DOS
        program.
      

      

        

          F10 opens the command menus. Left/Right changes menu; Up/Down chooses a command;
          Home/End jumps to the first/last command; Enter executes. Esc closes the menu and returns
          focus.
        

        

          F1 Help · F2 Save project · F3 Open project
F4 Open media
          · F5 Run · F6 Prepare
F7 Create · F8 Print ·
          F9 Palette
        

        

          Mouse interaction is disabled in DOS mode because period mouse support is not verified.
          Tab still reaches every control. Existing drawing keys, Ctrl/Cmd shortcuts, and canvas
          arrows continue to work. Shortcuts pause while typing or using a dialog. On a Mac, hold Fn
          if the function keys control hardware.
        

        

          On the canvas, arrows move the cursor. Enter paints a point, fills, picks a color, or
          places text, charts and pasted pictures. For lines, boxes, ellipses and selections, Enter
          sets the first corner; move with arrows and press Enter again. Esc cancels. Shift + arrows
          draws with Pencil or Erase. These keyboard operations are a usable reconstruction, not
          verified original key assignments.
        

        

          Use Full screen in the DOS title bar for an immersive workspace. Escape exits browser
          fullscreen; Windowed also exits it. Create opens drawing, toolbox, palette and
          picture-library controls. Prepare opens slide ordering, the slide directory and motion
          controls. Studio extras contains web project files, exports, fullscreen and help. The
          bottom task menu follows the documented Create / Prepare / Print / Run / Quit
          organization; submenu labels and exact layout are reconstructed. Quit directly returns to
          modern Studio without discarding work. Use Modern interface in the title bar to leave this
          interface. Switching interfaces preserves your slides, palette and unsaved edits.
